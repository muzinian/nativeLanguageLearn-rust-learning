# Rust 自适应复习：研究依据与外推边界

核对日期：2026-08-28。本文为课程复习规则提供依据，不记录学习者掌握状态；具体调度以 [教学计划第 8 节](../../RUST_TEACHING_PLAN.md#8-作业复习与源码阅读) 为准。

## 一手研究支持什么

### 1. 间隔有用，但没有适用于所有知识的固定日期表

Cepeda 等（2008）让 1,350 多名参与者学习事实材料，改变两次学习的间隔，并在不同延迟后测试。较长的目标保持时间通常对应较长的适宜学习间隔；间隔不是越长越好。这支持按保持目标安排分散练习，不能据此把统一的“第 1、7、28、56 天”称为每个人的最优记忆曲线。[原始论文：Spacing Effects in Learning](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf)

### 2. 主动提取优于只重读，眼下熟悉不等于延迟后仍能做

Roediger 与 Karpicke（2006）比较阅读材料后的重复学习与自由回忆。短延迟测试与数日后的测试呈现不同优势：重复阅读带来的当下表现和信心，并不能替代提取练习带来的延迟保持收益。因此应先让学习者解释、预测或实现，再针对失败补学，而不是先重讲整章。[原始论文及作者摘要：Test-Enhanced Learning](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/)

### 3. 跨日重新达到标准，比把大量练习挤在一次课里更值得关注

Rawson 与 Dunlosky（2011）的三项实验研究概念材料，比较首次学习的正确回忆次数与后续重新学习次数，并测量 1～4 个月后的保持和学习成本。后续重新学习明显改善保持，且削弱了首次大量练习的额外收益。这支持跨会话核验，而不是当堂答对一次就宣布稳定；论文在其材料上提出的次数建议，不能直接当作 Rust 模块能力的统一门槛。[原始论文作者摘要：Optimizing Schedules of Retrieval Practice](https://pubmed.ncbi.nlm.nih.gov/21707204/)

### 4. 要用新问题检验应用，不只重复原答案

Butler（2010）的四项实验比较重复测试与重复学习，并在一周后使用原问题、同领域新推理问题或跨领域新推理问题。重复测试对这些实验中的保持与迁移有益。课程因此可以采用变化输入、错误路径或业务背景的任务检验机制应用；但这些实验没有证明“会做概念推理题”就等于能够独立开发软件模块。[原始论文作者摘要：Repeated Testing Produces Superior Transfer](https://pubmed.ncbi.nlm.nih.gov/20804289/)

## 本课程的设计判断，不冒充实验结论

以下是结合现有课时、工程目标和学习记录可操作性制定的策略，不是上述论文验证过的最优参数：

- 以小能力单元调度，不把整周或整章当作复习项；一次仅保留一个下一次复习日期。
- 用延迟后的独立解释、实现/诊断与迁移证据判断稳定；具体间隔与成功次数是课程启发式，需要按实际表现调整。
- 稳定单元退出常规复习，不因进入新章节或日期过去就自动重开；在真实任务出现相关失败时，仅重新激活受影响单元。
- 后续项目中真实、独立的应用可以替代专门复习，必须记录覆盖的能力与证据；“项目包含此概念”本身不算掌握证明。
- 限制每次复习时间和数量；逾期不复制任务，不把漏掉的多个日期转换成多个补课义务。

“稳定退出”是一项成本与风险取舍，不代表永不遗忘；上述研究没有直接验证 Rust 学习者停止专项复习后的永久保持。本课程通过后续自然使用与失败重入控制风险，也不把缺少历史记录直接解释为忘记。

## 外推限制

这些研究主要涉及事实、文章和概念材料，不是 Rust 所有权设计、异步调试或团队交付的直接实验。因此只采用“分散练习、主动提取、延迟检查、观察迁移”的方向性依据。工程能力仍须由代码、测试、解释及陌生任务中的独立表现证明；不能根据记忆曲线公式计算一个未经验证的个人“掌握概率”，也不应把查阅生僻 API 文档等同于机制遗忘。
